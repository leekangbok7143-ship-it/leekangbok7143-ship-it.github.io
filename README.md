# 기록의 공간

GitHub Pages로 운영하는 개인 블로그입니다.

## 새 글 쓰기

1. 저장소의 `_posts` 폴더에서 **Add file → Create new file**을 선택합니다.
2. 파일 이름을 `YYYY-MM-DD-영문제목.md` 형식으로 입력합니다. 예: `2026-10-22-learning-notes.md`
3. 아래 서식을 복사해 제목과 날짜, 본문을 바꿉니다.

~~~markdown
---
layout: post
title: "글 제목"
date: 2026-10-22 09:00:00 +0900
categories: [기록]
---

여기에 글을 씁니다.
~~~

4. **Commit changes**를 누르면 GitHub Pages가 사이트를 자동으로 업데이트합니다.
